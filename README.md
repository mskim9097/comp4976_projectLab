# GradeCalc: Claude Code in VS Code lab

COMP 4976 term project lab starter.

This is a small C# console app that works out student grades. It has **3 bugs**, and some unit tests are failing on purpose. In the lab you will use the **Claude Code extension for VS Code** to find and fix them.

## Quick start

```bash
git clone https://github.com/mskim9097/comp4976_projectLab.git
cd comp4976_projectLab
dotnet test                     # expect: 15 total, 3 failed
dotnet run --project src/GradeCalc
```

Then open the folder in VS Code (`code .`) and follow the lab instructions.

## What is in here

| Path | What it is |
|---|---|
| `src/GradeCalc/GradeCalculator.cs` | The grade logic (the bugs are in here) |
| `src/GradeCalc/Program.cs` | Prints a small report for 3 sample students |
| `tests/GradeCalc.Tests/GradeCalculatorTests.cs` | xUnit tests. **Do not edit this file.** |
| `extras/team-rules.md` | Used in the optional CLAUDE.md step |

## Requirements

- .NET 10 SDK (`dotnet --version`)
- VS Code with the **Claude Code** extension
- A Claude Pro/Max/Team account or Claude Console (API) account. No account? Pair up with a classmate who has one.
